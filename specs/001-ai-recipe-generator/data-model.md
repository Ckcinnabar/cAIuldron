# Data Model: AI Recipe Generator

**Date**: 2025-10-16
**Branch**: 001-ai-recipe-generator

## Overview

This document defines the core entities and their relationships for the AI Recipe Generator system. All entities are designed to be technology-agnostic representations that can be implemented as Python dataclasses, Pydantic models, or database tables as needed.

## Core Entities

### 1. IngredientRecognitionResult

Represents the output from the computer vision model after analyzing an uploaded photo.

**Fields**:
- `ingredient_id`: string (USDA FoodData Central ID, e.g., "171077")
- `ingredient_name`: string (common name, e.g., "chicken breast")
- `confidence_score`: float (0.0-1.0, model confidence)
- `estimated_weight_grams`: float (estimated weight in grams)
- `estimated_volume_ml`: float (optional, for liquids/powders)
- `bounding_box`: object `{x: int, y: int, width: int, height: int}` (ingredient location in image)
- `quality_assessment`: enum (clear | unclear | too_far | multiple_items | not_food)
- `alternative_matches`: array of `{ingredient_name: string, confidence: float}` (top 3 alternatives)
- `image_url`: string (path to uploaded image)
- `created_at`: datetime

**Validation Rules**:
- `confidence_score` must be between 0.0 and 1.0
- If `confidence_score` < 0.6, `alternative_matches` must be provided
- `estimated_weight_grams` must be > 0
- `quality_assessment` triggers different UI flows (unclear → retake photo, multiple_items → select ingredient)

**Relationships**:
- One-to-many with Recipe (one ingredient → multiple recipe suggestions)

---

### 2. Recipe

Represents a complete cooking plan generated by the AI system.

**Fields**:
- `recipe_id`: UUID (unique identifier)
- `source_ingredient_id`: string (references IngredientRecognitionResult.ingredient_id)
- `title`: string (recipe name, e.g., "Teriyaki Chicken Stir-Fry")
- `cuisine_type`: enum (asian | western | fusion | mediterranean | latin | african | middle_eastern)
- `difficulty`: enum (beginner | intermediate | advanced)
- `total_cooking_time_minutes`: integer (total time from start to plate)
- `prep_time_minutes`: integer (preparation before cooking)
- `cook_time_minutes`: integer (active cooking time)
- `servings`: integer (number of servings this recipe yields)
- `ingredients`: array of RecipeIngredient `[{name: string, quantity: string, unit: string, optional: boolean}]`
- `cooking_steps`: array of CookingStep (ordered list of instructions)
- `nutritional_info`: NutritionalInformation (embedded object)
- `equipment_required`: array of string (e.g., ["wok", "cutting board", "knife"])
- `safety_validated`: boolean (TRUE if passed food safety checks)
- `safety_warnings`: array of string (any safety notes, e.g., "Ensure internal temp reaches 165°F")
- `rating`: float (optional, user-provided 0.0-5.0)
- `created_at`: datetime
- `last_modified_at`: datetime

**Validation Rules**:
- `total_cooking_time_minutes` = `prep_time_minutes` + `cook_time_minutes`
- `servings` must be ≥ 1
- `cooking_steps` must have at least 1 step
- `safety_validated` must be TRUE before recipe can be shown to users
- All protein recipes must have `safety_warnings` if cooking temperature mentioned

**Relationships**:
- Many-to-one with IngredientRecognitionResult (multiple recipes from one ingredient)
- One-to-many with CookingStep (recipe has multiple steps)
- One-to-one with NutritionalInformation (embedded)

---

### 3. CookingStep

Represents a single instruction in a recipe's cooking process.

**Fields**:
- `step_id`: UUID
- `recipe_id`: UUID (parent recipe)
- `step_number`: integer (1-indexed sequence)
- `instruction_text`: string (detailed text instruction)
- `estimated_time_minutes`: integer (time for this specific step)
- `illustration_url`: string (path to generated line-art image)
- `illustration_prompt`: string (prompt used to generate illustration, for reproducibility)
- `cooking_techniques`: array of string (e.g., ["dicing", "sautéing", "deglazing"])
- `temperature_fahrenheit`: integer (optional, for steps requiring specific heat)
- `temperature_celsius`: integer (optional, computed from fahrenheit)
- `ingredients_used`: array of string (which recipe ingredients used in this step)
- `equipment_needed`: array of string (specific equipment for this step)
- `tips`: array of string (helpful tips for beginners, e.g., "Use a sharp knife for clean cuts")

**Validation Rules**:
- `step_number` must be unique within a recipe and sequential (1, 2, 3...)
- `instruction_text` must be non-empty
- If `temperature_fahrenheit` provided, `temperature_celsius` auto-calculated
- `illustration_url` required for all steps in P3 (Step-by-Step Guide) user story

**Relationships**:
- Many-to-one with Recipe (step belongs to one recipe)

---

### 4. NutritionalInformation

Represents calculated nutrition data for a recipe.

**Fields**:
- `total_calories`: float (total calories for entire recipe)
- `calories_per_serving`: float (calories divided by servings)
- `protein_grams`: float (total protein in grams)
- `carbohydrates_grams`: float (total carbs in grams)
- `fat_grams`: float (total fat in grams)
- `fiber_grams`: float (optional, total dietary fiber)
- `sodium_mg`: float (optional, total sodium in milligrams)
- `servings`: integer (number of servings, matches Recipe.servings)
- `portion_size_grams`: float (average weight per serving)
- `data_source`: string (e.g., "USDA FoodData Central", "calculated")
- `accuracy_estimate`: enum (high | medium | low, based on estimation confidence)
- `calculation_notes`: string (e.g., "Includes added oil for cooking", "Based on standard portions")

**Validation Rules**:
- All gram/calorie values must be ≥ 0
- `calories_per_serving` = `total_calories` / `servings`
- `accuracy_estimate` = low if ingredient weight confidence < 0.7, else medium/high

**Relationships**:
- One-to-one with Recipe (embedded in Recipe object)

---

### 5. UserPreference (P4 Feature, Optional for MVP)

Represents user-specific settings for recipe customization.

**Fields**:
- `user_id`: UUID
- `dietary_restrictions`: array of enum (vegetarian | vegan | gluten_free | dairy_free | nut_free | shellfish_free | kosher | halal | paleo | keto | low_carb)
- `cuisine_preferences`: array of enum (asian | western | fusion | etc., or "no_preference")
- `equipment_available`: array of string (e.g., ["stovetop", "oven", "microwave", "air_fryer", "slow_cooker"])
- `max_cooking_time_minutes`: integer (optional, filter recipes by time)
- `skill_level`: enum (beginner | intermediate | advanced)
- `servings_preference`: integer (default number of servings to generate)
- `saved_recipe_ids`: array of UUID (list of favorited recipes)
- `allergens`: array of string (specific ingredients to avoid, e.g., ["peanuts", "soy"])
- `created_at`: datetime
- `last_updated_at`: datetime

**Validation Rules**:
- `max_cooking_time_minutes` must be > 0 if provided
- `dietary_restrictions` and `allergens` used to filter generated recipes
- `equipment_available` filters out recipes requiring unavailable equipment

**Relationships**:
- One-to-many with Recipe (via saved_recipe_ids)

## Pydantic Models (Python Implementation)

```python
from pydantic import BaseModel, Field, validator
from typing import List, Optional
from datetime import datetime
from enum import Enum
from uuid import UUID, uuid4

class QualityAssessment(str, Enum):
    CLEAR = "clear"
    UNCLEAR = "unclear"
    TOO_FAR = "too_far"
    MULTIPLE_ITEMS = "multiple_items"
    NOT_FOOD = "not_food"

class CuisineType(str, Enum):
    ASIAN = "asian"
    WESTERN = "western"
    FUSION = "fusion"
    MEDITERRANEAN = "mediterranean"
    LATIN = "latin"
    AFRICAN = "african"
    MIDDLE_EASTERN = "middle_eastern"

class Difficulty(str, Enum):
    BEGINNER = "beginner"
    INTERMEDIATE = "intermediate"
    ADVANCED = "advanced"

class AlternativeMatch(BaseModel):
    ingredient_name: str
    confidence: float = Field(ge=0.0, le=1.0)

class IngredientRecognitionResult(BaseModel):
    ingredient_id: str
    ingredient_name: str
    confidence_score: float = Field(ge=0.0, le=1.0)
    estimated_weight_grams: float = Field(gt=0)
    bounding_box: dict
    quality_assessment: QualityAssessment
    alternative_matches: List[AlternativeMatch] = []
    image_url: str
    created_at: datetime = Field(default_factory=datetime.now)

class RecipeIngredient(BaseModel):
    name: str
    quantity: str
    unit: str
    optional: bool = False

class NutritionalInformation(BaseModel):
    total_calories: float = Field(ge=0)
    calories_per_serving: float = Field(ge=0)
    protein_grams: float = Field(ge=0)
    carbohydrates_grams: float = Field(ge=0)
    fat_grams: float = Field(ge=0)
    servings: int = Field(ge=1)
    portion_size_grams: float = Field(ge=0)
    accuracy_estimate: str  # "high" | "medium" | "low"

class CookingStep(BaseModel):
    step_id: UUID = Field(default_factory=uuid4)
    step_number: int = Field(ge=1)
    instruction_text: str
    estimated_time_minutes: int = Field(ge=0)
    illustration_url: str
    cooking_techniques: List[str] = []
    temperature_fahrenheit: Optional[int] = None
    equipment_needed: List[str] = []

class Recipe(BaseModel):
    recipe_id: UUID = Field(default_factory=uuid4)
    source_ingredient_id: str
    title: str
    cuisine_type: CuisineType
    difficulty: Difficulty
    total_cooking_time_minutes: int = Field(ge=0)
    prep_time_minutes: int = Field(ge=0)
    cook_time_minutes: int = Field(ge=0)
    servings: int = Field(ge=1)
    ingredients: List[RecipeIngredient]
    cooking_steps: List[CookingStep]
    nutritional_info: NutritionalInformation
    equipment_required: List[str]
    safety_validated: bool
    safety_warnings: List[str] = []
    rating: Optional[float] = Field(None, ge=0.0, le=5.0)
    created_at: datetime = Field(default_factory=datetime.now)

    @validator('total_cooking_time_minutes')
    def validate_total_time(cls, v, values):
        if 'prep_time_minutes' in values and 'cook_time_minutes' in values:
            expected = values['prep_time_minutes'] + values['cook_time_minutes']
            assert v == expected, f"Total time must equal prep + cook ({expected})"
        return v
```

## Storage Considerations

**MVP (P1-P3)**:
- In-memory storage (Python dictionaries) for generated recipes
- Local filesystem for uploaded images and generated illustrations
- No persistent database required (stateless API)

**Future (P4 - User Preferences)**:
- PostgreSQL for user accounts, preferences, saved recipes
- S3/MinIO for image/illustration storage at scale
- Redis for caching common recipes

## Data Flow

1. **User uploads photo** → `IngredientRecognitionResult` created
2. **CV model analyzes** → Populate `ingredient_name`, `confidence_score`, `estimated_weight_grams`
3. **Recipe generation triggered** → Create 5-7 `Recipe` objects
4. **T5 model generates text** → Populate `title`, `ingredients`, `cooking_steps`, etc.
5. **Nutrition calculation** → Create `NutritionalInformation` from USDA data
6. **Safety validation** → Set `safety_validated` = TRUE/FALSE, add `safety_warnings`
7. **Illustration generation** → Generate line-art for each `CookingStep`, set `illustration_url`
8. **Response returned** → Full `Recipe` objects with all nested data
