# Data Model: AI-Powered Recipe Generator

**Feature**: AI-Powered Recipe Generator
**Date**: 2025-10-16
**Purpose**: Define data structures, entities, and relationships for the recipe generation system

## Core Entities

### 1. Ingredient

Represents the primary food item identified from an uploaded photo.

**Attributes**:
- `ingredient_id`: Unique identifier (string, UUID format)
- `name`: Common name (string, e.g., "chicken breast", "salmon fillet")
- `category`: Food category (string, e.g., "protein", "vegetable", "grain")
- `confidence_score`: AI recognition confidence (float, 0.0-1.0)
- `visual_characteristics`: Dict of detected features
  - `color`: Dominant color (string)
  - `texture`: Surface texture description (string)
  - `shape`: Basic shape category (string)
- `estimated_quantity`: Dict of size estimations
  - `weight_grams`: Estimated weight (float)
  - `volume_ml`: Estimated volume if applicable (float, optional)
  - `unit_count`: Number of items if countable (int, optional)
  - `confidence`: Size estimation confidence (float, 0.0-1.0)
- `reference_detected`: Whether size reference found in image (bool)
- `timestamp`: When ingredient was identified (datetime)

**Validation Rules**:
- `confidence_score` must be ≥ 0.7 for automatic processing
- `name` must match known ingredient database
- At least one quantity estimate must be present

**State Transitions**:
- `pending` → `identified` (when CNN processes successfully)
- `identified` → `verified` (if user confirms, optional)
- `identified` → `rejected` (if confidence too low, user re-uploads)

### 2. Recipe

Contains complete recipe information generated by AI models.

**Attributes**:
- `recipe_id`: Unique identifier (string, UUID format)
- `ingredient_id`: Reference to source ingredient (foreign key)
- `title`: Recipe name (string, max 100 chars)
- `cuisine_type`: Cuisine category (string, e.g., "Asian", "Western", "Fusion")
- `cooking_time_minutes`: Total cooking time (int)
- `difficulty_level`: Skill level required (enum: "beginner", "intermediate", "advanced")
- `serving_count`: Number of servings (int, 1-10)
- `ingredients_list`: List of required ingredients
  - Each item: `{name: str, quantity: str, unit: str, optional: bool}`
- `cooking_steps`: Ordered list of instructions (array of CookingStep)
- `portion_estimate`: Dict of serving information
  - `servings`: Number of servings (int)
  - `portion_size`: Size per serving (string, e.g., "200g")
- `calorie_estimate`: Nutritional information
  - `calories_per_serving`: Calories (float)
  - `confidence_interval`: (min, max) range (tuple of floats)
  - `macros`: Dict of macronutrients (optional)
    - `protein_g`: Protein in grams (float)
    - `carbs_g`: Carbohydrates in grams (float)
    - `fat_g`: Fat in grams (float)
- `ai_metadata`: Generation tracking
  - `transformer_model`: Model used (string)
  - `generation_timestamp`: When generated (datetime)
  - `rnn_refined`: Whether RNN post-processed (bool)
- `timestamp`: When recipe was created (datetime)

**Validation Rules**:
- `cooking_steps` must have at least 3 steps
- `cooking_time_minutes` must be > 0 and < 480 (8 hours)
- `ingredients_list` must include the source ingredient
- `difficulty_level` must match step complexity

**Relationships**:
- One Ingredient → Many Recipes (1:N)
- One Recipe → Many CookingSteps (1:N)
- One Recipe → One PortionEstimate (1:1)

### 3. CookingStep

Individual instruction in a recipe sequence.

**Attributes**:
- `step_id`: Unique identifier (string, UUID format)
- `recipe_id`: Parent recipe reference (foreign key)
- `step_number`: Order in sequence (int, 1-based)
- `instruction_text`: Detailed instruction (string, max 500 chars)
- `estimated_time_minutes`: Time for this step (int, optional)
- `cooking_method`: Primary technique (string, e.g., "sauté", "bake", "chop")
- `temperature`: Cooking temperature if applicable (dict, optional)
  - `value`: Temperature value (int)
  - `unit`: "celsius" or "fahrenheit" (string)
- `illustration_id`: Reference to visual guide (foreign key, optional)
- `tips`: Contextual cooking tips (array of strings, optional)
- `technique_explanations`: Dict of term definitions (optional)
  - `{technique_name: explanation_text}`
- `timing_alert`: Whether step needs timer (bool)
- `dependencies`: List of prerequisite step numbers (array of ints)

**Validation Rules**:
- `step_number` must be sequential within recipe
- `instruction_text` must contain an action verb
- `dependencies` must reference valid earlier steps only (no circular deps)
- If `timing_alert` is true, `estimated_time_minutes` must be present

**Relationships**:
- One Recipe → Many CookingSteps (1:N)
- One CookingStep → One Illustration (1:1, optional)

### 4. Illustration

Line-art visual guide for a cooking step.

**Attributes**:
- `illustration_id`: Unique identifier (string, UUID format)
- `step_id`: Associated cooking step (foreign key)
- `image_data`: Illustration content
  - `format`: "SVG" or "PNG" (string)
  - `file_path`: Path to stored image (string)
  - `width_px`: Image width (int, default 512)
  - `height_px`: Image height (int, default 512)
- `style_metadata`: Visual properties
  - `line_weight`: Stroke thickness (float, 1.5-3.0)
  - `color_scheme`: Color palette (string, default "monochrome")
  - `complexity`: Detail level (enum: "simple", "moderate", "detailed")
- `generation_metadata`: AI tracking
  - `gan_model`: Model used (string)
  - `generation_seed`: Reproducibility seed (int)
  - `quality_score`: Automated quality check (float, 0.0-1.0)
- `alt_text`: Accessibility description (string, max 200 chars)
- `timestamp`: When illustration was generated (datetime)

**Validation Rules**:
- `image_data.format` must be "SVG" or "PNG"
- `quality_score` must be ≥ 0.6 for automatic approval
- `alt_text` must describe the cooking action shown

**Relationships**:
- One CookingStep → One Illustration (1:1, optional)

### 5. PortionEstimate

Calculated serving and nutritional information.

**Attributes**:
- `estimate_id`: Unique identifier (string, UUID format)
- `recipe_id`: Parent recipe reference (foreign key)
- `ingredient_id`: Source ingredient reference (foreign key)
- `servings`: Number of servings (int)
- `portion_size_per_serving`: Size description (string, e.g., "200g", "1 cup")
- `total_weight_grams`: Total recipe weight (float)
- `calories_per_serving`: Calorie estimate (float)
- `calorie_range`: Confidence interval
  - `min`: Minimum calories (float)
  - `max`: Maximum calories (float)
  - `confidence_level`: Probability level (float, typically 0.8)
- `macronutrients`: Optional detailed breakdown
  - `protein_grams`: Protein per serving (float)
  - `carbs_grams`: Carbs per serving (float)
  - `fat_grams`: Fat per serving (float)
  - `fiber_grams`: Fiber per serving (float, optional)
- `estimation_method`: How calculated (string, e.g., "bayesian_pgm", "usda_lookup")
- `data_sources`: List of nutritional DB references (array of strings)
- `uncertainty_factors`: Known sources of variation (array of strings)
- `timestamp`: When estimate was calculated (datetime)

**Validation Rules**:
- `calories_per_serving` must be > 0 and < 5000 (reasonable max)
- `calorie_range.min` ≤ `calories_per_serving` ≤ `calorie_range.max`
- `servings` must match Recipe.serving_count
- If macronutrients present, protein + carbs + fat must sum reasonably close to total calories

**Relationships**:
- One Recipe → One PortionEstimate (1:1)
- One Ingredient → Many PortionEstimates (1:N, through recipes)

## Data Flow

### 1. Photo Upload → Ingredient Identification

```
User uploads photo
    ↓
CNN processes image
    ↓
Create Ingredient entity
    - Extract: name, category, confidence
    - Estimate: quantity (weight, volume, count)
    - Detect: visual characteristics
    ↓
If confidence ≥ 0.7: proceed
If confidence < 0.7: request user confirmation
```

### 2. Ingredient → Recipe Generation

```
Ingredient identified
    ↓
Transformer generates 5 recipes (parallel)
    - Vary cuisine_type for diversity
    - Match difficulty to ingredient complexity
    ↓
For each recipe:
    Create Recipe entity
    - Link to ingredient_id
    - Store: title, cuisine, difficulty, ingredients_list
    ↓
    RNN refines cooking_steps
    - Adjust cooking_time_minutes
    - Reorder steps for logical flow
    - Add estimated_time_minutes per step
    ↓
    Create CookingStep entities (sequential)
    - Link to recipe_id
    - Store: instruction_text, cooking_method, timing
```

### 3. Recipe → Nutrition Estimation

```
Recipe with ingredients_list created
    ↓
PGM processes ingredient + portions
    ↓
Create PortionEstimate entity
    - Calculate: calories_per_serving, macros
    - Estimate: portion_size from ingredient quantity
    - Generate: calorie_range with confidence interval
    ↓
Link PortionEstimate to Recipe
```

### 4. Cooking Steps → Illustrations

```
CookingStep entities created
    ↓
For each step with visual action:
    GAN generates line-art illustration
    ↓
    Create Illustration entity
    - Link to step_id
    - Store: image_data, style_metadata
    - Generate: alt_text for accessibility
    ↓
    Link Illustration to CookingStep
```

## Data Storage

### Notebook-Specific Storage Strategy

**Structured Data** (JSON format):
- `data/processed/ingredients/` - Ingredient entities
- `data/processed/recipes/` - Recipe entities
- `data/results/generated_recipes/` - Final recipe outputs

**Model Outputs** (Parquet format for efficiency):
- `data/results/cnn_predictions.parquet` - Ingredient predictions with confidence
- `data/results/transformer_recipes.parquet` - Raw generated recipes
- `data/results/rnn_refinements.parquet` - Step adjustments
- `data/results/pgm_nutrition.parquet` - Nutrition estimates

**Media Assets**:
- `data/results/illustrations/{recipe_id}/` - Generated line-art images
- `data/raw/ingredient_images/` - Uploaded user photos (temporary)

**Model Checkpoints**:
- `models/` - Trained model weights (.h5, .pt, .pkl files)

### Data Versioning

- Use timestamps in filenames: `recipe_{recipe_id}_{timestamp}.json`
- Maintain data manifests: `data/processed/manifest.json` with checksums
- Store metadata: model version, generation params with each output

## Validation & Quality Checks

### Ingredient Validation
- ✅ Confidence score ≥ 0.7
- ✅ Name exists in ingredient database
- ✅ Quantity estimate is reasonable for ingredient type
- ✅ At least one size metric (weight, volume, or count)

### Recipe Validation
- ✅ Minimum 3 cooking steps
- ✅ All ingredients in list are known
- ✅ Source ingredient is included in ingredients_list
- ✅ Cooking time > 0 and < 480 minutes
- ✅ Difficulty matches step complexity (beginner: simple methods, advanced: complex techniques)

### CookingStep Validation
- ✅ Sequential step numbers (no gaps)
- ✅ Instruction contains action verb
- ✅ Dependencies only reference earlier steps
- ✅ No circular dependencies
- ✅ If timing_alert = true, estimated_time_minutes must be set

### Illustration Validation
- ✅ Image file exists at specified path
- ✅ Quality score ≥ 0.6
- ✅ Dimensions match specification (512x512)
- ✅ Alt text describes the action shown

### PortionEstimate Validation
- ✅ Calories > 0 and < 5000 per serving
- ✅ Calorie range: min ≤ actual ≤ max
- ✅ Servings match recipe serving_count
- ✅ Macros sum approximately equals calorie total (protein×4 + carbs×4 + fat×9)
